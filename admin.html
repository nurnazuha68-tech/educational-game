เพิ่มรายการใหม่

กรอกข้อมูลเป็น JSON โดยใช้ชื่อคอลัมน์ให้ตรงกับฐานข้อมูล ไม่ต้องใส่ id เมื่อเพิ่มรายการใหม่

หมายเหตุเกี่ยวกับสิทธิ์

ระบบจะตรวจสอบบทบาท Admin ผ่าน Supabase ก่อนเปิดแดชบอร์ด การเพิ่ม แก้ไข หรือลบข้อมูลยังขึ้นอยู่กับ Row Level Security (RLS) และสิทธิ์ที่กำหนดไว้ในฐานข้อมูล
